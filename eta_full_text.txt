Entropy-weighted Asymmetry Transformation (EAT) for methylation profiles.
Given Beta(a,B) centroids for Healthy (H) and Cancer (C), we compute a per-locus
distortion T_i that emphasizes loci whose Beta *shape* differs (skew/asymmetry),
and de-emphasizes loci with high/indistinguishable entropy.
Core idea:

Ti = Avi * (1 + |AC,i - A_H,il) * exp(-y * |H_C,i - H_H,il)
where

Ap_i = w_C,i - w_H,i = a_C/(a_C+B_C) - a_H/(a_H+B_H)

A i= (ai - B i)/(a_i+ Bi) (asymmetry index)

H(a,B) is the Beta entropy:

H = In B(a,B) - (a-1)b(a) - (B-1)¥(B) + (at+B-2)p(a+B)

You then reweight each sample vector x_s (f-values per locus) as:

x' Ss = xX_S © T (elementwise)
and optionally normalize per-sample before classification.
Improvements:
- Added shape validation for input arrays.
- Optional Normal approximation fallback for low-coverage (small a+) cases.
- GPU compatibility via xp (NumPy or CuPy).
- Overflow handling for large a/B using log-gamma approximations.
- Additional normalization options ('11', 'minmax').
- Vectorized and robust to edge cases.
