Introduction

MethylCentroid is a high-performance computational framework for calculating methylation centroids from genomic data. This document provides a comprehensive theoretical foundation for the algorithms, statistical methods, and computational approaches implemented in the MethylCentroid software package.

Core Theoretical Foundations

  • Methylation Centroid Calculation: Statistical aggregation of methylation data across samples
  • Multi-Metric Consensus: Robust outlier detection using multiple distance metrics with consensus requirements
  • Position Alignment Algorithms: Efficient genomic coordinate alignment across samples
  • Beta Distribution Modeling: Probabilistic modeling of methylation levels
  • GPU Acceleration: High-performance computing integration

Methylation Data Model

Methylation Representation

DNA methylation involves the addition of a methyl group to cytosine nucleotides, primarily at CpG dinucleotides. In MethylCentroid, methylation data is represented using the following notation:

  • mCᵢ: Count of methylated cytosines at position i
  • uCᵢ: Count of unmethylated cytosines at position i
  • Nᵢ: Number of samples contributing to position i
  • posᵢ: Genomic coordinate of position i
  • xᵢ = mCᵢ/(mCᵢ + uCᵢ): Methylation level at position i (0 ≤ xᵢ ≤ 1)

HDF5 Data Structure

Methylation data is stored in HDF5 format with the following structure:

methylation_data/
├── pos     # uint32: Genomic positions
├── mC      # uint32: Methylated cytosine counts
├── uC      # uint32: Unmethylated cytosine counts
├── tnc     # uint8:  Trinucleotide context codes
└── N       # uint32: Number of samples (for centroids)

Centroid Calculation

Basic Centroid Definition

A methylation centroid represents the average methylation pattern across a group of samples. For each genomic position, the centroid is calculated as:

Basic Centroid Formula:

centroid.mCᵢ = Σⱼ₌₁ᴺ mCᵢⱼ / N
centroid.uCᵢ = Σⱼ₌₁ᴺ uCᵢⱼ / N
centroid.Nᵢ = N

where N is the number of samples, and mCᵢⱼ and uCᵢⱼ are the methylated and unmethylated counts for sample j at position i.

Extended Centroid with Statistical Measures

The extended centroid includes additional statistical measures for advanced analysis:

Extended Centroid Formula:

centroid.mCᵢ = Σⱼ₌₁ᴺ mCᵢⱼ / N
centroid.uCᵢ = Σⱼ₌₁ᴺ uCᵢⱼ / N
centroid.Sxᵢ = Σⱼ₌₁ᴺ xᵢⱼ
centroid.Sx2ᵢ = Σⱼ₌₁ᴺ xᵢⱼ²
centroid.log_x_sumᵢ = Σⱼ₌₁ᴺ log(xᵢⱼ)
centroid.log_1_minus_x_sumᵢ = Σⱼ₌₁ᴺ log(1 - xᵢⱼ)

where xᵢⱼ = mCᵢⱼ/(mCᵢⱼ + uCᵢⱼ) is the methylation level for sample j at position i.

Methylation Level Calculation

Critical Distinction: The methylation level calculation differs between basic and extended centroids:

  • Basic Centroid: methylation_level = mC / (mC + uC) (average of raw counts)
  • Extended Centroid: methylation_level = Sx / N (correct statistical estimator)

Important: These formulas are not equivalent when different positions have different sample counts. The extended centroid formula Sx/N is the correct statistical estimator that properly accounts for the number of samples contributing to each position.

Coverage-Based Filtering

Positions are included in the centroid only if they meet minimum coverage criteria:

Coverage Filter:

mCᵢ + uCᵢ ≥ min_coverage    ∀ i ∈ valid_positions

Multi-Metric Consensus Outlier Detection

Multi-Metric Consensus Approach

MethylCentroid employs a sophisticated multi-metric consensus system for robust outlier detection. Rather than relying on a single distance metric, the system combines multiple complementary distance measures and requires consensus among them before classifying a sample as an outlier. This approach significantly reduces false positives and improves the reliability of outlier detection by leveraging the strengths of different distance metrics while mitigating their individual weaknesses.

Information-Theoretic Distance Measures

The multi-metric system incorporates four distinct distance measures, each with unique properties and sensitivities to different types of methylation patterns. These metrics work together to provide comprehensive coverage of potential outlier characteristics.

For two probability distributions p and q, the Kullback-Leibler divergence is:

Kullback-Leibler Divergence:

D_KL(p||q) = Σᵢ pᵢ log(pᵢ/qᵢ)

Entropy Weighting

MethylCentroid uses entropy-based weighting to emphasize positions with lower uncertainty (higher certainty) in the centroid. The entropy of a methylation level cᵢ is:

Entropy:

H(cᵢ) = -[cᵢ log(cᵢ) + (1-cᵢ) log(1-cᵢ)]

Weights are calculated as the inverse of entropy:

Weights:

wᵢ = 1 / (H(cᵢ) + ε), where ε ≈ 10⁻¹⁰

Normalized weights ensure they sum to 1:

Normalized Weights:

w̃ᵢ = wᵢ / Σⱼ wⱼ

Entropy-Weighted Jensen-Shannon Divergence Definition

Jensen-Shannon divergence is defined as the average of the Kullback-Leibler divergences between each distribution and their mixture:

Jensen-Shannon Divergence:

JS(p,q) = ½[D_KL(p||m) + D_KL(q||m)]

where m = ½(p + q) is the mixture distribution.

Jensen-Shannon Divergence Properties

JS divergence has several key advantages for outlier detection:

  • Bounded: 0 ≤ JS(p,q) ≤ 1 (when using base-2 logarithm)
  • Symmetric: JS(p,q) = JS(q,p)
  • Metric: Satisfies triangle inequality
  • Interpretable: 0 = identical distributions, 1 = maximally different

Entropy-Weighted Jensen-Shannon Divergence for Methylation Data

For methylation samples represented as vectors of methylation levels x = (x₁, x₂, ..., xₙ) and centroid c = (c₁, c₂, ..., cₙ), the Jensen-Shannon divergence per position is:

Methylation Jensen-Shannon Divergence per Position:

JSᵢ(xᵢ, cᵢ) = ½ [xᵢ log(xᵢ/mᵢ) + cᵢ log(cᵢ/mᵢ)]

where mᵢ = ½(xᵢ + cᵢ) is the mixture at position i.

For outlier detection, MethylCentroid uses the entropy-weighted Jensen-Shannon divergence:

Entropy-Weighted Jensen-Shannon Divergence:

JSD_w(x, c) = Σᵢ₌₁ⁿ w̃ᵢ · JSᵢ(xᵢ, cᵢ)

This weighting scheme ensures that positions with lower entropy (higher certainty) in the centroid contribute more to the overall divergence measure, making the algorithm more sensitive to positions where the centroid is well-defined. The entropy-weighted formulation provides bounded [0,1] values that are ideal for statistical modeling and Beta distribution fitting.

Consensus Mechanism

The multi-metric consensus system operates through a sophisticated voting mechanism that ensures robust outlier classification:

Consensus Algorithm

  1. Distance Calculation: Each configured metric calculates distances between all samples and the centroid
  2. Statistical Modeling: P-values are computed for each metric using appropriate statistical distributions (Normal or Beta)
  3. Outlier Voting: Each metric "votes" for samples with p-value < α (significance threshold)
  4. Consensus Decision: Samples are classified as outliers only if they receive votes from at least min_metrics_agree metrics
  5. Most Extreme Selection: Among consensus outliers, the sample with the lowest combined p-value is selected for removal (most extreme)

Consensus Formula

Consensus Rule:

Sample is outlier if: |{m : p_value_m < α}| ≥ min_metrics_agree

where p_value_m is the p-value from metric m, and min_metrics_agree is the minimum number of metrics that must agree.

Benefits of Multi-Metric Consensus

  • Reduced False Positives: Multiple metrics must agree, reducing spurious outlier classifications
  • Increased Reliability: Consensus approach is more robust to metric-specific biases
  • Adaptive Sensitivity: Can adjust consensus requirements based on data characteristics
  • Statistical Rigor: Each metric provides independent evidence for outlier classification
  • Comprehensive Coverage: Different metrics capture different aspects of sample-centroid relationships

Multiple Distance Metrics for Robust Outlier Detection

MethylCentroid supports four complementary distance metrics, each with unique properties and sensitivities to different types of methylation patterns. The combination of these metrics provides comprehensive coverage for outlier detection.

Jeffreys Divergence

Jeffreys divergence is the symmetric version of Kullback-Leibler divergence:

Jeffreys Divergence:

J(P,Q) = D(P||Q) + D(Q||P) = Σᵢ pᵢ log(pᵢ/qᵢ) + Σᵢ qᵢ log(qᵢ/pᵢ)

Properties:

  • Symmetric: J(P,Q) = J(Q,P)
  • Non-negative: J(P,Q) ≥ 0
  • Unbounded: Can grow without limit
  • Good for detecting large differences

Jensen-Shannon Divergence

Jensen-Shannon divergence is a symmetric, bounded measure of similarity between distributions:

Jensen-Shannon Divergence:

JS(P,Q) = ½[D(P||M) + D(Q||M)]

where M = ½(P + Q) is the mixture distribution.

Properties:

  • Bounded [0,1]: 0 = identical, 1 = maximally different
  • Symmetric: JS(P,Q) = JS(Q,P)
  • Metric: Satisfies triangle inequality
  • Robust: Less sensitive to outliers than KL divergence

Weighted Jensen-Shannon Divergence

Entropy-weighted version that emphasizes positions with lower uncertainty:

Weighted Jensen-Shannon Divergence:

JSD_w(x,c) = Σᵢ₌₁ⁿ w̃ᵢ · JSᵢ(xᵢ,cᵢ)

where w̃ᵢ = 1/(H(cᵢ) + ε) are entropy-based weights.

Properties:

  • Bounded [0,1]
  • Emphasizes certain positions
  • More sensitive to well-defined patterns
  • Ideal for high-confidence outlier detection

Hellinger Distance

Hellinger distance is a symmetric, bounded metric based on the square root of probabilities:

Hellinger Distance:

H(P,Q) = √(½ Σᵢ (√pᵢ - √qᵢ)²)

Properties:

  • Bounded [0,1]: 0 = identical, 1 = maximally different
  • Symmetric: H(P,Q) = H(Q,P)
  • Metric: Satisfies triangle inequality
  • Robust: Less sensitive to extreme values
  • Good for detecting distribution shape differences

Statistical Distribution Modeling for Multi-Metric Outlier Detection

The multi-metric consensus system employs a sophisticated statistical approach for each distance metric, automatically selecting between Normal and Beta distributions based on which provides a better fit to the observed distance values. This ensures that each metric uses the most appropriate statistical model for its specific distance distribution characteristics.

Theoretical Considerations

When analyzing distance values across samples for each metric, two competing theoretical models emerge. The choice between Normal and Beta distributions depends on the specific properties of each distance metric:

  • Beta Distribution Model: Ideal for bounded metrics (Jensen-Shannon, Weighted Jensen-Shannon, Hellinger) that are inherently bounded [0,1]. The Beta distribution naturally models bounded continuous variables and provides better statistical properties for these metrics.
  • Normal Distribution Model: Suitable for unbounded metrics (Jeffreys divergence) or when the Central Limit Theorem applies due to averaging across many genomic positions. The Normal distribution provides good approximations for many distance distributions.

Multi-Metric Considerations: Each metric may have different optimal distribution models, and the algorithm automatically selects the best model for each metric independently, ensuring optimal statistical performance across all distance measures.

Configuration and Practical Usage

The multi-metric consensus system is highly configurable, allowing users to adapt the approach to their specific data characteristics and analysis requirements:

Metric Selection

Users can configure which distance metrics to use based on their data characteristics:

  • All Four Metrics (Recommended): Provides maximum robustness and comprehensive coverage
  • Bounded Metrics Only: Jensen-Shannon, Weighted Jensen-Shannon, and Hellinger for bounded data
  • Single Metric: Traditional approach using only one metric (e.g., Weighted Jensen-Shannon)
Consensus Requirements

The consensus requirement can be adjusted based on the desired sensitivity and specificity trade-off:

  • Conservative (3 out of 4): Reduces false positives, suitable for high-confidence outlier detection
  • Strict (4 out of 4): Maximum reliability, very low false positive rate
  • Liberal (2 out of 4): Higher sensitivity, may increase false positives
  • Single Metric (1 out of 1): Traditional single-metric approach

A typical configuration for robust outlier detection:

Distribution Fitting and Model Selection

The algorithm implements an automated model selection process using Akaike Information Criterion (AIC) with optimized parameter estimation:

Optimized Beta Parameter Estimation

The algorithm uses a two-tier approach for Beta parameter estimation, prioritizing speed while maintaining robustness:

Primary: Method of Moments

First attempts fast method of moments estimation by converting Normal distribution parameters to Beta parameters:

α = μ²(1-μ)/σ² - μ
β = α(1-μ)/μ

This approach is:

  • Much faster: O(1) vs O(n) for MLE fitting
  • Mathematically equivalent: Uses the same statistical relationships
  • Sufficiently accurate: For most outlier detection purposes
Fallback: Maximum Likelihood Estimation

If method of moments fails (invalid parameters or edge cases), falls back to robust MLE fitting:

# Fallback to expensive but robust MLE fitting
beta_params = beta.fit(dists_array, floc=0, fscale=1)
beta_a, beta_b, _, _ = beta_params

This ensures:

  • Robustness: Handles edge cases and unusual data distributions
  • Reliability: Always produces valid Beta parameters
  • Accuracy: Maximum likelihood estimation when needed

Step 1: Beta Distribution Fitting

# Fit Beta distribution with fixed location and scale
beta_params = beta.fit(dists_array, floc=0, fscale=1)
beta_a, beta_b, _, _ = beta_params

Step 2: Normal Distribution Parameter Estimation

# Estimate Normal distribution parameters using method of moments
μ = np.nanmean(dists_array)  # Sample mean
σ = np.nanstd(dists_array)   # Sample standard deviation

Step 3: Log-Likelihood Calculation

# Calculate log-likelihoods for both distributions
beta_loglik = np.sum(beta.logpdf(dists_array, beta_a, beta_b, loc=0, scale=1))
normal_loglik = np.sum(norm.logpdf(dists_array, μ, σ))

Step 4: AIC-Based Model Selection

# AIC = 2k - 2ln(L) where k = number of parameters, L = likelihood
beta_aic = 2 * 2 - 2 * beta_loglik      # 2 parameters for Beta (a, b)
normal_aic = 2 * 2 - 2 * normal_loglik  # 2 parameters for Normal (μ, σ)

# Select the model with lower AIC (better fit)
use_beta = beta_aic < normal_aic and beta_a > 0 and beta_b > 0

P-Value Calculation

Once the optimal distribution is selected, p-values are calculated using the appropriate cumulative distribution function:

Beta Distribution P-Value:

p_value = 1 - beta.cdf(obs_value, beta_a, beta_b, loc=0, scale=1)
# Additional safety check: p_value = 0 if obs_value >= 1.0

Normal Distribution P-Value:

p_value = 1 - norm.cdf(obs_value, μ, σ)
# Additional safety check: p_value = 0 if σ <= 0
Edge Case Handling for Bounded Metrics

For bounded distance metrics like Hellinger distance [0,1], special handling is required when all distances are identical (σ = 0). This edge case occurs when all samples have the same distance to the centroid, which can happen with very similar samples or when using a single metric.

Edge Case Logic:

if σ > 0:
    # Standard case: use normal CDF
    p_values = 1 - norm.cdf(distances, μ, σ)
else:
    # Edge case: all distances are identical
    if μ >= 0.99:  # Close to maximum (e.g., Hellinger = 1.0)
        p_values = np.zeros_like(distances)  # p-value = 0.0 (most extreme)
    elif μ <= 0.01:  # Close to minimum (e.g., Hellinger = 0.0)
        p_values = np.ones_like(distances)   # p-value = 1.0 (least extreme)
    else:
        # Intermediate values: neutral p-value
        p_values = np.full_like(distances, 0.5)

Mathematical Justification:

  • Maximum Distance (μ ≈ 1.0): When all samples have maximum distance to the centroid, they are all maximally different and should be considered extreme outliers (p-value = 0.0)
  • Minimum Distance (μ ≈ 0.0): When all samples have minimum distance to the centroid, they are all very similar and should not be considered outliers (p-value = 1.0)
  • Intermediate Distance (0.01 < μ < 0.99): When all samples have intermediate distance, the situation is ambiguous and a neutral p-value (0.5) is assigned

This approach ensures that bounded metrics like Hellinger distance correctly identify extreme cases where all samples are maximally different from the centroid, which should result in p-values approaching 0.0 rather than 1.0.

Robustness and Fallback Mechanisms

The algorithm includes several robustness features:

  • Parameter Validation: Beta parameters must be positive (a > 0, b > 0)
  • Numerical Stability: Normal distribution requires σ > 0
  • Exception Handling: If Beta fitting fails, automatically falls back to Normal distribution
  • Boundary Conditions: Handles edge cases where observed values exceed distribution bounds
  • Edge Case Handling: Properly handles cases where all distances are identical (σ = 0) with appropriate p-value assignment based on distance magnitude
  • Bounded Metric Support: Special handling for bounded metrics [0,1] to ensure correct p-value calculation for extreme cases

Multi-Metric Consensus Outlier Detection Algorithm

The complete multi-metric consensus outlier detection algorithm follows these steps:

Initialization Phase

  1. Centroid Calculation: Compute extended centroid from all active samples
  2. Configuration Loading: Load distance metrics and consensus parameters from configuration
  3. Sample Preparation: Identify active samples (those currently included in centroid calculation)

Iterative Outlier Detection

For each iteration (1 to max_iterations):

  1. Multi-Metric Distance Calculation:
    • For each configured distance metric (Jeffreys, Jensen-Shannon, Weighted Jensen-Shannon, Hellinger)
    • Calculate distances between all active samples and the centroid
    • Use parallel processing for efficient computation across all samples
  2. Statistical Modeling and P-Value Computation:
    • For each distance metric independently:
    • Apply statistical distribution selection (Normal vs Beta) using AIC
    • Calculate p-values for all samples using the selected distribution
    • Handle edge cases (σ = 0) with appropriate p-value assignment
  3. Consensus-Based Outlier Classification:
    • For each sample, count how many metrics classify it as an outlier (p-value < α)
    • Apply consensus requirement: sample is outlier if |{m : p_value_m < α}| ≥ min_metrics_agree
    • Identify qualified outliers that meet the consensus threshold
  4. Most Extreme Outlier Selection:
    • Among qualified outliers, calculate combined p-values (minimum across all metrics)
    • Select the sample with the lowest combined p-value as the most extreme outlier
    • Generate histogram visualization for the primary metric (first in configuration)
  5. Outlier Removal Decision:
    • If no qualified outliers exist: exit iteration loop
    • If most extreme p-value > α: no significant outliers found - exit
    • If minimum samples threshold reached: stop outlier removal
    • Otherwise: proceed with outlier removal
  6. Sample Removal and Centroid Update:
    • Remove the identified outlier from active samples
    • Add to outliers set for tracking
    • Recalculate extended centroid from remaining active samples
    • Save current state and iteration information

Algorithm Termination

The algorithm terminates when any of these conditions are met:

  • No Qualified Outliers: No samples meet the consensus requirement
  • No Significant Outliers: Most extreme p-value exceeds significance threshold α
  • Minimum Sample Threshold: Number of active samples falls below min_samples
  • Maximum Iterations: Reached the configured maximum number of iterations

Statistical Interpretation

The multi-metric consensus approach provides several statistical advantages:

  • Robust P-Value Calculation: Each metric provides independent evidence for outlier classification, with p-values representing the probability of observing distances as extreme as the observed values under the null hypothesis
  • Consensus-Based Classification: The requirement for multiple metrics to agree reduces false positives and increases reliability, as each metric captures different aspects of sample-centroid relationships
  • Adaptive Distribution Selection: The automatic selection between Normal and Beta distributions ensures that each metric uses the most appropriate statistical model for its specific distance distribution characteristics
  • Edge Case Handling: Special handling for cases where all distances are identical (σ = 0) ensures correct p-value assignment for extreme cases in bounded metrics
  • Comprehensive Coverage: Different metrics provide complementary information:
    • Jeffreys Divergence: Information-theoretic divergence, sensitive to probability distribution differences
    • Jensen-Shannon Divergence: Bounded, symmetric measure of distribution similarity
    • Weighted Jensen-Shannon: Entropy-weighted version emphasizing positions with higher certainty
    • Hellinger Distance: Robust metric based on square root of probabilities, less sensitive to extreme values

Algorithm Complexity

The multi-metric consensus algorithm has the following complexity characteristics:

  • Distance Calculation: O(M × N × P) where M = number of metrics, N = number of samples, P = number of positions
  • Statistical Modeling: O(M × N) for distribution fitting and p-value calculation
  • Consensus Classification: O(M × N) for outlier voting and consensus determination
  • Overall Per Iteration: O(M × N × P) dominated by distance calculations
  • Total Complexity: O(I × M × N × P) where I = number of iterations

Position Alignment Algorithm

Problem Statement

Genomic methylation data from different samples may have different position sets due to: - Sequencing coverage variations - Quality filtering differences - Biological differences in methylation patterns

Dynamic Position Range Expansion

The PositionAligner implements a dynamic position management system:

Algorithm Overview: 1. Initialize empty position set 2. For each sample s: - Load positions P_s = {p₁, p₂, ..., pₙ} - Find intersection: P_common = P_current ∩ P_s - Find new positions: P_new = P_s - P_current - Expand accumulators for new positions - Update accumulators for common positions - P_current = P_current ∪ P_s 3. Return aligned position data

Memory-Efficient Accumulators

The algorithm maintains running accumulators for each genomic position:

Accumulator Updates:

mC_sum[p] += mC_s,p
uC_sum[p] += uC_s,p
N[p] += 1
Sx[p] += x_s,p
Sx2[p] += x_s,p²
log_x_sum[p] += log(x_s,p)
log_1_minus_x_sum[p] += log(1 - x_s,p)

Computational Complexity

The position alignment algorithm achieves O(N log M) complexity where: - N: number of samples - M: average number of positions per sample

This is achieved through: - Efficient numpy intersect1d operations - Sparse accumulator updates - Memory-mapped array operations

Statistical Distribution Selection: Mathematical Foundations

Akaike Information Criterion (AIC)

The AIC is a model selection criterion that balances model fit with model complexity. It is defined as:

AIC = 2k - 2ln(L)

where: - k = number of parameters in the model - L = likelihood of the model given the data - ln(L) = log-likelihood

AIC Interpretation

  • Lower AIC indicates better model fit relative to model complexity
  • Difference in AIC (ΔAIC) between models indicates relative support:
    • ΔAIC < 2: Substantial support for both models
    • 2 ≤ ΔAIC < 4: Considerable support for the better model
    • 4 ≤ ΔAIC < 7: Less support for the worse model
    • ΔAIC ≥ 7: Essentially no support for the worse model

Beta Distribution Theory

The Beta distribution is particularly well-suited for modeling bounded data like Jeffreys divergence values. It is defined on the interval [0,1] with probability density function:

f(x; α, β) = x^(α-1) * (1-x)^(β-1) / B(α, β)

where B(α, β) is the Beta function and α, β > 0 are shape parameters.

Beta Distribution Properties

  • Support: [0, 1] (perfect for bounded divergence values)
  • Shape flexibility: Can model symmetric, skewed, U-shaped, and J-shaped distributions
  • Conjugate prior: Natural choice for binomial/Bernoulli data
  • Sufficient statistics: log(x) and log(1-x) sums

Normal Distribution Theory

The Normal distribution is often appropriate due to the Central Limit Theorem when averaging across many positions:

f(x; μ, σ) = (1/√(2πσ²)) * exp(-(x-μ)²/(2σ²))

where μ is the mean and σ is the standard deviation.

Central Limit Theorem Application

When Jeffreys divergence is calculated across many genomic positions, the distribution of divergence values may approximate normality due to:

  • Independence assumption: Positions are approximately independent
  • Finite variance: Divergence values have bounded variance
  • Large sample size: Many positions contribute to each divergence calculation

Model Selection Algorithm

The complete model selection process in MethylCentroid follows this algorithm:

  1. Data Preparation:
    • Collect Jeffreys divergence values: D = {d₁, d₂, ..., dₙ}
    • Ensure data is properly bounded and contains no invalid values
  2. Beta Distribution Fitting:
    • Use maximum likelihood estimation: β̂ = argmax L(α, β | D)
    • Fix location=0, scale=1 to constrain to [0,1] interval
    • Validate parameters: α̂ > 0, β̂ > 0
  3. Normal Distribution Estimation:
    • Use method of moments: μ̂ = (1/n)Σdᵢ, σ̂ = √((1/n)Σ(dᵢ-μ̂)²)
    • Validate parameters: σ̂ > 0
  4. Log-Likelihood Calculation:
    • Beta: ln L_B = Σᵢ ln f(dᵢ; α̂, β̂)
    • Normal: ln L_N = Σᵢ ln f(dᵢ; μ̂, σ̂)
  5. AIC Calculation:
    • AIC_B = 2×2 - 2×ln L_B
    • AIC_N = 2×2 - 2×ln L_N
  6. Model Selection:
    • If AIC_B < AIC_N and α̂ > 0 and β̂ > 0: Select Beta
    • Otherwise: Select Normal

P-Value Calculation: Mathematical Details

Once the optimal distribution is selected, the p-value calculation follows standard statistical testing procedures:

Beta Distribution P-Value

p-value = 1 - F_B(obs_value; α̂, β̂)

where F_B is the cumulative distribution function of the Beta distribution.

Normal Distribution P-Value

p-value = 1 - Φ((obs_value - μ̂)/σ̂)

where Φ is the cumulative distribution function of the standard normal distribution.

Statistical Power and Type I Error

The choice of distribution directly impacts the statistical properties of the outlier detection:

Distribution Type I Error Control Statistical Power Robustness
Beta Better for bounded data Higher for extreme values More sensitive to outliers
Normal Conservative for bounded data Lower for extreme values More robust to outliers

Practical Example: Distribution Selection

Consider a scenario with 100 samples and the following average Jensen-Shannon divergence per position values:

Example Data:
  • Average divergences per sample: [0.12, 0.08, 0.15, 0.09, 0.11, ..., 0.13] (100 values)
  • Each value represents the mean Jensen-Shannon divergence across all genomic positions for that sample
  • Observed maximum: 0.45 (potential outlier)
  • Mean (μ): 0.11, Standard deviation (σ): 0.03

Step 1: Fast Beta Parameter Estimation

# Method of moments: convert Normal parameters to Beta parameters
# α = μ²(1-μ)/σ² - μ, β = α(1-μ)/μ
beta_a = μ * μ * (1 - μ) / (σ * σ) - μ
beta_b = beta_a * (1 - μ) / μ
# Result: α = 12.3, β = 98.7 (much faster than beta.fit())

Step 2: Log-Likelihood Calculation

beta_loglik = np.sum(beta.logpdf(dists_array, 12.3, 98.7, loc=0, scale=1))
# Result: -45.2

normal_loglik = np.sum(norm.logpdf(dists_array, 0.11, 0.03))
# Result: -38.7

Step 3: AIC Comparison

AIC_beta = 2 * 2 - 2 * (-45.2) = 94.4
AIC_normal = 2 * 2 - 2 * (-38.7) = 81.4

# Since AIC_normal < AIC_beta, select Normal distribution

Step 4: P-Value Calculation

# Using Normal distribution
z = (0.45 - 0.11) / 0.03 = 11.33
p_value = 1 - norm.cdf(11.33) ≈ 0.0  # Highly significant outlier

Interpretation: The algorithm selected the Normal distribution based on AIC, and the observed divergence of 0.45 is highly significant (p ≈ 0.0), indicating a clear outlier.

Beta Distribution Modeling

Methylation Level Distribution

Methylation levels at individual CpG sites often follow Beta distributions due to their bounded nature (0 ≤ x ≤ 1). The Beta distribution is parameterized by shape parameters α and β:

Beta Distribution PDF:

f(x; α, β) = x^(α-1) * (1-x)^(β-1) / B(α, β)

where B(α, β) is the Beta function.

Sufficient Statistics

The extended centroid accumulates sufficient statistics for Beta distribution fitting:

Beta Sufficient Statistics:

log_x_sum = Σᵢ₌₁ᴺ log(xᵢ)
log_1_minus_x_sum = Σᵢ₌₁ᴺ log(1 - xᵢ)

Maximum Likelihood Estimation

Beta distribution parameters are estimated using maximum likelihood:

Log Likelihood:

log L(α, β) = N log Γ(α + β) - N log Γ(α) - N log Γ(β) + (α - 1) log_x_sum + (β - 1) log_1_minus_x_sum

Statistical Testing

The Beta distribution parameters enable various statistical tests: - Goodness-of-fit tests for methylation patterns - Confidence intervals for methylation levels - Hypothesis testing for differential methylation - Bayesian inference for methylation states

Mathematical Derivations (Appendix)

Derivation of Jeffreys Divergence for Methylation Data

For methylation data, each position represents a Bernoulli trial with success probability xᵢ. The probability mass function is:

P(Xᵢ = 1) = xᵢ,    P(Xᵢ = 0) = 1 - xᵢ

For two methylation profiles x and c, the Jeffreys divergence becomes:

J(x, c) = ½ Σᵢ₌₁ⁿ [xᵢ log(xᵢ/cᵢ) + (1-xᵢ) log((1-xᵢ)/(1-cᵢ)) + cᵢ log(cᵢ/xᵢ) + (1-cᵢ) log((1-cᵢ)/(1-xᵢ))]

This formulation is equivalent to the symmetrized Kullback-Leibler divergence for Bernoulli distributions.

Beta Distribution Parameter Estimation

The maximum likelihood estimators for Beta distribution parameters can be obtained by solving:

ψ(α + β) - ψ(α) = (1/N) Σᵢ₌₁ᴺ log xᵢ
ψ(α + β) - ψ(β) = (1/N) Σᵢ₌₁ᴺ log(1 - xᵢ)

where ψ is the digamma function. These equations are solved numerically using optimization algorithms.

Derivation of Jensen-Shannon Divergence

Jensen-Shannon divergence is derived from the Kullback-Leibler divergence by considering the mixture distribution. For two probability distributions P and Q, the mixture is M = ½(P + Q).

Jensen-Shannon Divergence:

JS(P,Q) = ½[D_KL(P||M) + D_KL(Q||M)]

For methylation data with methylation levels xᵢ and cᵢ:

JS(x,c) = ½ Σᵢ₌₁ⁿ [xᵢ log(2xᵢ/(xᵢ+cᵢ)) + cᵢ log(2cᵢ/(xᵢ+cᵢ))]

Derivation of Weighted Jensen-Shannon Divergence

The entropy-weighted version incorporates position-specific weights based on the entropy of the centroid:

Entropy:

H(cᵢ) = -[cᵢ log(cᵢ) + (1-cᵢ) log(1-cᵢ)]

Weights:

wᵢ = 1/(H(cᵢ) + ε), w̃ᵢ = wᵢ/Σⱼ wⱼ

Weighted Jensen-Shannon Divergence:

JSD_w(x,c) = Σᵢ₌₁ⁿ w̃ᵢ · JSᵢ(xᵢ,cᵢ)

Derivation of Hellinger Distance

Hellinger distance is based on the L² norm of the difference between square roots of probability distributions:

Hellinger Distance:

H(P,Q) = √(½ Σᵢ (√pᵢ - √qᵢ)²)

For methylation data:

H(x,c) = √(½ Σᵢ₌₁ⁿ (√xᵢ - √cᵢ)²)
