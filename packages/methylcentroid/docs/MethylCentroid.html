Project Overview

MethylCentroid is a high-performance Python package for calculating methylation centroids from genomic data. It provides both basic and extended centroid calculations with multi-metric consensus outlier detection, making it ideal for analyzing methylation patterns across biological replicates or similar samples.

Key Innovation: MethylCentroid uses a multi-metric consensus approach for robust outlier detection, combining Jeffreys Divergence, Jensen-Shannon Divergence, Weighted Jensen-Shannon Divergence, and Hellinger Distance. The system requires multiple metrics to agree before classifying a sample as an outlier, significantly reducing false positives and improving reliability. All metrics are bounded [0,1] and automatically select between Normal and Beta distribution models using optimized parameter estimation.

Multiple Distance Metrics for Robust Outlier Detection

MethylCentroid supports multiple distance metrics and can require consensus across metrics for more reliable outlier detection:

Available Distance Metrics

  • Jeffreys Divergence: Symmetric version of Kullback-Leibler divergence
  • Jensen-Shannon Divergence: Bounded [0,1], symmetric, satisfies triangle inequality
  • Weighted Jensen-Shannon Divergence: Entropy-weighted version emphasizing certain positions
  • Hellinger Distance: Bounded [0,1], symmetric, robust to outliers

Multi-Metric Consensus

  • Configurable Metrics: Choose one or more distance metrics (default: all four metrics)
  • Consensus Requirement: Require multiple metrics to agree on outliers (default: 3 out of 4)
  • Robust Detection: Significantly reduces false positives and improves reliability
  • Flexible Configuration: Adapt to different data characteristics via config.json
  • Statistical Rigor: Each metric provides independent evidence for outlier classification

Optimized Parameter Estimation

MethylCentroid uses a three-tier approach for maximum efficiency:

  1. Method of Moments (Fast): O(1) conversion from Normal to Beta parameters
  2. Maximum Likelihood (Robust): Falls back to MLE when needed
  3. Simple Estimation (Safety): Ensures algorithm never fails

Core Capabilities

  • Centroid Calculation: Compute average methylation patterns across sample groups
  • Multi-Metric Outlier Detection: Identify outliers using consensus of multiple distance metrics
  • GPU Acceleration: Transparent GPU support for large-scale genomic data processing
  • Adaptive Statistics: Automatic selection of appropriate statistical distributions
  • Configuration Management: JSON-based configuration for easy setup and reproducibility
  • Batch Processing: Efficient processing of multiple chromosomes/contexts

Multi-Metric Distance Formulas:
Jeffreys: J(x,c) = (1/n) Σᵢ [xᵢlog(xᵢ/cᵢ) + cᵢlog(cᵢ/xᵢ)]
Jensen-Shannon: JS(x,c) = (1/2)[D(x||m) + D(c||m)] where m = (x+c)/2
Weighted JS: JS_w(x,c) = Σᵢ wᵢ·JSᵢ(xᵢ,cᵢ) where wᵢ = 1/(H(cᵢ)+ε)
Hellinger: H(x,c) = √(1/2 Σᵢ (√xᵢ - √cᵢ)²)

Methylation Level Calculation

Important Distinction: Methylation levels are calculated differently for basic vs extended centroids:
  • Basic Centroid: methylation_level = mC / (mC + uC) (average of raw counts)
  • Extended Centroid: methylation_level = Sx / N (correct statistical estimator)
Note: These formulas are not equivalent when different positions have different sample counts. The extended centroid formula Sx/N is the correct statistical estimator used in outlier detection.

Statistical Innovation

MethylCentroid introduces several statistical innovations for methylation analysis:

  • Multi-Metric Consensus: Combines multiple distance metrics for robust outlier detection
  • Entropy-Weighted Jensen-Shannon: Emphasizes positions with higher certainty in the centroid
  • Bounded Data Handling: Proper statistical treatment of methylation data bounded in [0,1]
  • Adaptive Distribution Fitting: Automatic model selection between Normal and Beta distributions
  • Consensus-Based Testing: Requires multiple metrics to agree before classifying outliers
  • Percentage-based Iteration Limits: Dynamic iteration limits based on sample size
  • Robust P-value Calculation: Handles edge cases where all distances are identical (σ=0) with appropriate p-value assignment

P-value Calculation for Bounded Metrics

For bounded distance metrics like Hellinger distance [0,1], MethylCentroid uses sophisticated p-value calculation:

  • Normal Distribution: When σ > 0, uses standard normal CDF: p = 1 - Φ((x - μ)/σ)
  • Beta Distribution: When data characteristics suggest Beta distribution, uses Beta CDF for more accurate modeling
  • Edge Case Handling: When σ = 0 (all distances identical), assigns p-values based on distance magnitude:
    • Maximum distance (≈1.0): p-value = 0.0 (most extreme)
    • Minimum distance (≈0.0): p-value = 1.0 (least extreme)
    • Intermediate distances: p-value = 0.5 (neutral)

Multi-Metric Consensus System

Overview

MethylCentroid's multi-metric consensus system provides robust outlier detection by combining multiple distance metrics and requiring agreement across metrics before classifying a sample as an outlier. This approach significantly reduces false positives and improves the reliability of outlier detection.

Distance Metrics

Jeffreys Divergence

Symmetric version of Kullback-Leibler divergence, providing information-theoretic distance between probability distributions.

Jensen-Shannon Divergence

Bounded [0,1], symmetric, and satisfies the triangle inequality. Provides stable distance measurement.

Weighted Jensen-Shannon Divergence

Entropy-weighted version that emphasizes positions with higher certainty in the centroid, making it more sensitive to informative positions.

Hellinger Distance

Bounded [0,1], symmetric, and robust to outliers. Provides complementary information to divergence-based metrics.

Consensus Mechanism

The consensus system works as follows:

  1. Distance Calculation: Each configured metric calculates distances between samples and the centroid
  2. P-value Computation: Statistical p-values are computed for each metric using appropriate distributions
  3. Outlier Voting: Each metric "votes" for samples with p-value < α
  4. Consensus Decision: Samples are classified as outliers only if they receive votes from at least min_metrics_agree metrics
  5. Most Extreme Selection: Among consensus outliers, the sample with the lowest combined p-value is selected (most extreme)

Configuration Examples

Strict Approach (All metrics must agree)

{ "distance_metrics": ["weighted_jensen_shannon"], "min_metrics_agree": 1 }

Benefits of Multi-Metric Consensus

  • Reduced False Positives: Multiple metrics must agree, reducing spurious outlier classifications
  • Improved Reliability: Consensus approach is more robust to metric-specific biases
  • Flexible Configuration: Adapt the consensus requirement to your data characteristics
  • Statistical Rigor: Each metric provides independent evidence for outlier classification
  • Comprehensive Coverage: Different metrics capture different aspects of sample-centroid relationships
