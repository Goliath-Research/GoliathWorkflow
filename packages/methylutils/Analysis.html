1. Theoretical Foundation: MethylSample and Beta Distributions

Methylation levels (beta values, β ∈ [0,1]) at CpG sites are modeled as realizations from a Beta distribution because they arise from binomial processes (methylated vs. unmethylated reads) with unknown success probabilities. The Beta(α, β) distribution is a conjugate prior for the binomial likelihood, making it ideal for aggregating samples into centroids.

  • MethylSample as Foundation:

    • MethylSample (in methyl_utils/methyl_sample.py) represents either:
      • A single sample: Raw counts (pos, mC (methylated), uC (unmethylated), tnc (context)).
      • A basic centroid: Aggregated counts + N (sample count per position) + Sx (sum of β values) + Sx2 (sum of squared β values).
      • An extended centroid: Above + log_x_sum (∑ log(β)) + log_1_minus_x_sum (∑ log(1-β)) for sufficient statistics.
    • Centroids represent group averages: For a group of samples, the centroid's effective β at position i is the average methylation level, but stored as sufficient statistics to avoid recomputing from raw data.
    • Key properties (computed on-demand, cached for efficiency):
      • mean: E[β] = α / (α + β). For small N (≤10), uses empirical mean (Sx/N); for large N (>10), uses Beta mean to leverage distributional info.
      • variance: Var[β] = [αβ / (α+β)²] / (α+β+1) — decreases as α+β (precision τ) increases.
      • alpha, beta: Shape parameters, exposing the full Beta distribution for the group's methylation at each position.
      • tau (precision): α + β, roughly proportional to effective sample size (N × average coverage).

  • Parameter Estimation (α, β):

    • In _compute_beta_parameters():
      • Extended centroids (preferred, uses log sums): Maximum Likelihood Estimation (MLE) via beta_mle_estimation (from methyl_utils/statistical_tests.py), which solves the score equations using digamma functions. Falls back to bounded Method of Moments (MoM) if MLE fails (e.g., α/β < 1e-6 or non-finite).
        • Formula (simplified): α ≈ n × mean, β ≈ n × (1 - mean), but adjusted via log-likelihood optimization for bias correction.
        • Bounds: Clipped to [1e-6, 1e5] to prevent extremes; if mean deviates >0.5 from empirical, reverts to conservative MoM (α = mean × 50, β = (1-mean) × 50).
      • Basic centroids: MoM via beta_mom_estimation: α = (Sx² / (N × Sx² - Sx²)) × (N-1), but simplified to α ≈ mean × (N-1), β ≈ (1-mean) × (N-1).
      • Single samples: MoM via get_sample_beta_mom (from methyl_utils/metrics_core.py): α = β_level × (coverage-1), β = (1-β_level) × (coverage-1), where β_level = mC / (mC+uC). Falls back to uniform Beta(1,1) for low coverage (<2).
    • Why Beta? For a group (centroid), the posterior over site-specific methylation probabilities is Beta(∑mC + α_prior, ∑uC + β_prior). With flat priors (α_prior=β_prior=1), it's approximately Beta(∑β × N, ∑(1-β) × N). Large N makes the distribution peaked around the group mean, with variance ~1/(4N) for mean=0.5.

  • Probability of Sample Belonging to Centroid:

    • Theoretically, for a sample with methylation levels {x_i} at positions {i}, the likelihood under the centroid's Beta model is:
      P({x_i} | centroid) = ∏_i Beta(x_i | α_i, β_i)
log P = ∑_i log[Beta(x_i | α_i, β_i)] = ∑_i [(α_i-1) log(x_i) + (β_i-1) log(1-x_i) - log B(α_i, β_i)]
      • log B(α,β) is the log-Beta function (via scipy.special.betaln or gammaln(α+β) - gammaln(α) - gammaln(β)).
      • For "belonging probability", in single-centroid contexts (e.g., outlier detection), this is often the (normalized) log-likelihood.
      • In multi-centroid contexts (e.g., classification via MethylCentroidPair or clustering), it's the posterior probability:
        P(centroid_k | {x_i}) ∝ P({x_i} | centroid_k) × P(centroid_k)
        • Assuming equal priors P(centroid_k)=1/K, posterior = softmax([log P({x_i} | k)]_k) = exp(log L_k) / ∑ exp(log L_j).
      • Normalization: Often averaged by #valid positions (coverage >0, α/β >0) for comparability across samples/sites.

2. Code Implementation: Where and How Probabilities Are Calculated

The calculation spans methylutils (core utils) and consuming packages. No single "probability" method exists for arbitrary centroids—it's contextual (clustering vs. classification). Key implementations:

  • Core Log-PDF Computation (methyl_utils/beta_analytics.py):

    • beta_log_pdf(x, a, b, use_gpu=True): Computes ∑ log Beta(x_i | α_i, β_i) efficiently (GPU via CuPy if available). Clips x to [1e-12, 1-1e-12] to avoid log(0). Uses vectorized betaln for stability.
    • Used everywhere for likelihoods. No direct probability—exponentiating the sum gives likelihood (not normalized probability).

  • Single Centroid: Log-Likelihood for Belonging (Clustering/Outlier Detection):

    • In methylcluster/methyl_cluster/centroid_manager.py (ClusterCentroid.compute_log_likelihood(sample)):
      • Aligns sample and centroid positions (common_pos = intersect(pos_sample, pos_centroid)).
      • Computes sample β: x = mC / (mC + uC), clipped [1e-6, 1-1e-6], filtered by coverage >0.
      • Gets centroid α, β via centroid._compute_beta_parameters() (caches to avoid recompute).
      • Valid positions: coverage >0 & α>0 & β>0.
      • log L = ∑ beta_log_pdf(x_valid, α_valid, β_valid) / #valid_positions (average for normalization).
      • Returns average log-likelihood (higher = better fit). For assignment: argmax over centroids' log L.
      • No explicit probability: Used for relative comparison (e.g., EM clustering in methyl_cluster/cluster.py:_assign_samples_to_centroids). To get "probability", one could softmax over centroids, but code uses hard assignment.
      • In methylcentroid/methyl_centroid.py (outlier detection): Similar, but uses scipy.stats.beta.logpdf for probabilistic outlier scoring (fits Beta/Normal to distances, computes p-values). Extreme probs here from fitting to scaled distances [0.001,0.999].

  • Multi-Centroid: Posterior Probability (Classification via MethylCentroidPair):

    • MethylCentroidPair (in methyl_utils/methyl_centroid_pair.py): Compares two centroids (e.g., disease vs. control) for DMP detection (methyldetector). Computes α1/β1, α2/β2 via MethylSample.alpha/beta. Used in MethylDetector._detect_statistical_dmps to get DMPs with stats (p/q-values, means, Bhattacharyya distance).
      • No direct sample classification here—focuses on centroid comparison (LRT via likelihood_ratio_test_beta for DMP p-values).
    • Classification: In methyl_utils/probabilistic_beta_classifier.py (ProbabilisticBetaClassifier):
      • Trained on DMPs from MethylCentroidPair (data = {'alpha1','beta1','alpha2','beta2', ...}).
      • predict_proba(X) (X = [n_samples, n_dmps] methylation matrix):
        • Clips X to [1e-6,1-1e-6].
        • Broadcasts α0/β0 (class 0/centroid1), α1/β1 (class 1/centroid2) over samples.
        • log L_0 = ∑_j beta.logpdf(X[:,j], α0[:,j], β0[:,j]) (sum over DMPs j; masks invalid α/β≤0 or NaN).
        • log L_1 similarly.
        • Handles availability_mask (e.g., missing CpGs): Sets logpdf=0 for unavailable.
        • If no valid positions: log L = 0 (neutral).
        • Posterior: softmax(log L) = exp(log L_k - max) / ∑ exp(log L_j - max) (log-sum-exp for stability; assumes equal priors).
      • Used in methyltrainer (MethylTrainer._create_classifier): Builds classifier from biological DMPs, calibrates directions (flips if improves logpdf fit), validates on held-out samples.
      • In methyldetector/core/classify.py: Legacy scalar version using log_pdf_beta (same formula), computes P_C = 1 / (1 + exp(-(sumLLR + log_prior_odds))), where sumLLR = ∑ log(Beta(x|aC,bC)/Beta(x|aH,bH)).
      • Integration: MethylClassifier (in methylclassifier) loads trained classifier from MethylTrainer, uses predict_proba for new samples.

  • Other Usages:

    • methyltrainer/trainer_class.py: In _calibrate_directions, tests direction flips by comparing average logpdf under correct vs. flipped models—extreme probs would amplify here if one model fits much better.
    • No explicit single-centroid "probability" beyond log L; belonging is relative (e.g., > threshold or argmax).

3. Root Cause: Why Probabilities Are Almost Always 0 or 1

Your observation of "very low or high probabilities, almost 0 or 1 all the time" is not a bug but a statistical consequence of the model and data characteristics. Here's the breakdown:

  • Peaked Distributions from Large Precision (τ = α + β):

    • For centroids with many samples (large N, high coverage), τ ≈ N × coverage (e.g., N=50 samples, coverage=30 → τ~1500). The Beta pdf is extremely peaked: Var[β] ≈ 1/(4τ) → very small (~0.0001).
    • logpdf(x | α,β) is high only if x is very close to mean (±√Var). Even small deviations (e.g., x = mean + 0.01) yield logpdf << 0 (e.g., -10 to -50 per site).
    • Code: In beta_log_pdf, no smoothing beyond clipping—direct computation amplifies this.

  • Accumulation Over Many Independent Sites (DMPs):

    • Methylation sites are assumed independent. log L = ∑_sites logpdf(x_site) over ~100-1000 DMPs (from MethylDetector).
    • Small per-site mismatch (e.g., logpdf diff = -0.05, common for slight biological variation) → total diff = -5 to -50.
    • In softmax: If log L_1 - log L_0 = Δ > 5, P_1 ≈ 1 - exp(-Δ) ≈ 1 (e.g., Δ=10 → P=0.99995; Δ=20 → P=1-2e-9).
    • Code: predict_proba sums logpdf (lines 145-146), then softmax (177-178). Normalization by #sites (in clustering) helps comparability but doesn't prevent extremes in softmax.
    • In single-centroid: If computing P(belong) = exp(log L) / Z (Z=normalizing constant, often ignored), log L is hugely negative (product of ~100 pdfs ~0.01 each → log L ~ -460), but relative comparison still extreme.

  • No Regularization or Priors Mitigating Overconfidence:

    • Equal priors (0.5) in softmax—no class imbalance adjustment.
    • No temperature scaling (softmax with T>1 softens extremes) or Platt calibration.
    • Missing data: Masked (logpdf=0), but if many missing, falls to neutral (0.5), but with full data, extremes dominate.
    • High-dimensional curse: With d=100+ sites, even weak signals compound (law of large numbers makes posteriors concentrate).

  • Evidence from Code:

    • Debug in predict_proba (lines 159-172): Prints log L (often -100s) and fractions valid (~0.8-1.0). If Δ log L >5-10 (common), probs extreme.
    • In methyldetector/core/classify.py: Uses logistic: P_C = 1/(1+exp(-sumLLR)), where sumLLR amplifies per-site diffs.
    • No complaints in logs/docs, but METHYL_CENTROID_PAIR_SIMPLIFICATION.md notes focus on stats, not calibration—extremes expected in raw posteriors.
    • Numerical stability: Clipping prevents NaN/inf, but doesn't soften peaks (e.g., MIN_BETA_PARAM=1e-6 in MoM).

  • When/Where You See Extremes:

    • Classification (MethylClassifier): predict_proba outputs near-0/1 for most samples, as sumLLR >>0 or <<0.
    • Clustering (MethylCluster): Assignments are hard (argmax log L), but if softmaxed for soft assignment, extremes.
    • Outlier Detection (MethylCentroid): Beta-fit p-values can be extreme if distances deviate from peaked fit.
    • Low-coverage sites: Uniform Beta(1,1) (flat pdf) softens, but high-coverage dominate.

4. Recommendations for Revision (Without Breaking Foundation)

To address extremes while keeping MethylSample intact:

  • Use Average Log-Likelihood: In ProbabilisticBetaClassifier.predict_proba, divide sum by n_dmps (like clustering) before softmax—reduces amplification.
  • Add Temperature: Softmax(log L / T) with T=2-5 (tune on validation).
  • Prior on Precision: Shrink τ toward smaller values (e.g., α' = (1-λ)α + λ*1, λ~0.1/N) to broaden pdfs.
  • Site Selection: Use fewer, high-weight DMPs (from MethylTrainer biological filtering).
  • Calibration: Post-hoc Platt scaling on held-out data to map raw probs to calibrated [0.1,0.9].
  • Single-Centroid Prob: If needed, define as exp(average log L - max_over_null), with null=uniform Beta(1,1).
