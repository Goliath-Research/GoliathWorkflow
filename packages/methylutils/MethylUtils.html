📋 Overview

MethylUtils is a comprehensive Python package for statistical analysis of methylation data with advanced GPU acceleration support. Built with a modular factory pattern architecture, it provides high-performance implementations of various statistical distance metrics for Beta distributions commonly used in methylation analysis.

🎯 Key Features

  • 🚀 GPU Acceleration: Automatic GPU detection with NVIDIA GH200 optimization
  • 🏭 Factory Pattern: Extensible architecture for easy metric addition
  • ⚡ Memory Efficient: In-place operations and optimized memory usage
  • 🔒 Type Safe: Full type hints with comprehensive validation
  • 📊 Statistical Rigor: Mathematically accurate implementations
  • 🔧 Modular Design: Clean separation of concerns

🧬 Applications

  • Methylation level comparison between samples
  • Differential methylation analysis
  • Centroid-based clustering of methylation profiles
  • Statistical validation of methylation differences
  • FDR correction for multiple testing
  • Meta-analysis of methylation studies

🔬 Mathematics

This section provides the mathematical foundations for all implemented distance metrics. All formulas are derived from probability theory and information theory principles.

📊 Beta Distribution Fundamentals

The Beta distribution is fundamental to methylation analysis because methylation levels follow this distribution naturally:

$$\Beta(\alpha, \beta) = \frac{\Gamma(\alpha + \beta)}{\Gamma(\alpha)\Gamma(\beta)} x^{\alpha-1}(1-x)^{\beta-1}$$

where:

  • $\alpha$ = number of methylated reads + 1
  • $\beta$ = number of unmethylated reads + 1
  • $x \in [0,1]$ represents methylation level

📏 Distance Metrics

Kullback-Leibler Divergence

$$D_{KL}(P||Q) = \int p(x) \log\left(\frac{p(x)}{q(x)}\right) dx$$

For Beta distributions:

$$D_{KL}(\Beta(\alpha_1,\beta_1)||\Beta(\alpha_2,\beta_2)) = (\alpha_1 - \alpha_2)(\psi(\alpha_1) - \psi(\alpha_1 + \beta_1)) + (\beta_1 - \beta_2)(\psi(\beta_1) - \psi(\alpha_1 + \beta_1)) + \log\left(\frac{\Beta(\alpha_2,\beta_2)}{\Beta(\alpha_1,\beta_1)}\right)$$

where $\psi$ is the digamma function and $\Beta$ is the Beta function.

Jensen-Shannon Distance

$$D_{JS}(P||Q) = \sqrt{JS(P||Q)}$$

where:

$$JS(P||Q) = \frac{1}{2} D_{KL}(P||M) + \frac{1}{2} D_{KL}(Q||M)$$

and $M = \frac{1}{2}(P + Q)$ is the mixture distribution.

Range: $[0, 1]$ (symmetric metric)

Jeffreys Divergence

$$D_J(P||Q) = D_{KL}(P||Q) + D_{KL}(Q||P)$$

This is the symmetrized KL divergence, providing a true distance metric.

Bhattacharyya Distance

$$D_B(P||Q) = -\log(BC(P,Q))$$

where $BC(P,Q)$ is the Bhattacharyya coefficient:

$$BC(P,Q) = \int \sqrt{p(x)q(x)} dx$$

For Beta distributions:

$$BC(\Beta(\alpha_1,\beta_1), \Beta(\alpha_2,\beta_2)) = \frac{\Gamma\left(\frac{\alpha_1+\alpha_2}{2}\right)\Gamma\left(\frac{\beta_1+\beta_2}{2}\right)}{\sqrt{\Gamma(\alpha_1)\Gamma(\beta_1)\Gamma(\alpha_2)\Gamma(\beta_2)}} \cdot \frac{\Gamma\left(\frac{\alpha_1+\alpha_2+\beta_1+\beta_2}{2}\right)}{\Gamma\left(\frac{\alpha_1+\beta_1}{2} + \frac{\alpha_2+\beta_2}{2}\right)}$$

Hellinger Distance

$$D_H(P||Q) = \sqrt{1 - BC(P,Q)}$$

Range: $[0, 1]$ (true metric)

Wasserstein Distance (Approximate)

$$W_1(P,Q) \approx |\mu_P - \mu_Q| + |\sigma_P - \sigma_Q|$$

where $\mu$ and $\sigma$ are the mean and standard deviation of the distributions.

For Beta distributions:

$$\mu = \frac{\alpha}{\alpha + \beta}, \quad \sigma = \sqrt{\frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}}$$

Weighted Jensen-Shannon Distance

$$D_{WJS}(P||Q) = \sqrt{w_1 D_{KL}(P||M) + w_2 D_{KL}(Q||M)}$$

where $M = w_1 P + w_2 Q$ is the weighted mixture, and $w_1 + w_2 = 1$.

📈 Statistical Tests

Storey's q-values (FDR Correction)

$$\pi_0(\lambda) = \frac{\#\left\{p_i > \lambda\right\}}{(1-\lambda)m}$$ $$q_i = \min_{j=m}^i \pi_0 p_{(j)}$$

where $p_{(j)}$ are the sorted p-values and $\pi_0$ is the estimated proportion of true null hypotheses.

Stouffer's Method

$$Z = \frac{\sum_{i=1}^k w_i z_i}{\sqrt{\sum_{i=1}^k w_i^2}}, \quad z_i = \Phi^{-1}(p_i)$$

where $\Phi^{-1}$ is the inverse normal CDF and $w_i$ are optional weights.

🔍 Entropy-Based Weighting

$$H(p) = -\sum p_i \log p_i$$

For methylation data, entropy weights are calculated as:

$$w_i = 1 - H(p_i)$$

This gives higher weights to positions with higher uncertainty (lower confidence in methylation calls).

💡 Usage Examples

Basic Distance Computation

import numpy as np
from methyl_utils import auto_compute_distance

# Sample methylation data (alpha, beta parameters)
a1, b1 = np.array([10, 15, 8]), np.array([5, 3, 12])   # Sample 1
a2, b2 = np.array([12, 12, 6]), np.array([4, 6, 14])   # Sample 2

# Compute Jensen-Shannon distance
jsd = auto_compute_distance(a1, b1, a2, b2, metric="jensen_shannon")
print(f"JSD: {jsd}")
# Output: [0.123, 0.234, 0.089]

Multiple Metrics Comparison

from methyl_utils import get_metric_factory

factory = get_metric_factory()
metrics = ["jeffreys", "hellinger", "jensen_shannon", "wasserstein"]

for metric in metrics:

    print(f"{metric}: {result}")

GPU Optimization Strategies

Memory Management

  • Float32 precision: Optimal for GPU memory bandwidth
  • In-place operations: Minimize memory allocations
  • Batch processing: Process multiple comparisons simultaneously
  • Memory pooling: Reuse allocated memory blocks

Performance Best Practices

# ✅ Recommended: Let GPU detection be automatic
result = auto_compute_distance(a1, b1, a2, b2)

# ✅ Good: Specify GPU usage explicitly when needed
result = auto_compute_distance(a1, b1, a2, b2, use_gpu=True)

# ⚠️ Avoid: Unnecessary data transfers
# Don't convert between CPU/GPU repeatedly in loops

# ✅ Good: Batch operations
batch_results = []
for i in range(0, len(data), batch_size):
    batch_a1, batch_b1 = data[i:i+batch_size]
    batch_result = auto_compute_distance(batch_a1, batch_b1, a2, b2)
    batch_results.append(batch_result)

Memory Usage Optimization

Data Types

  • Input validation: Convert to float32 early
  • Intermediate results: Use float32 consistently
  • Output precision: Maintain float64 for final results if needed

Large Dataset Handling

# For datasets larger than available GPU memory
def process_large_dataset(a1, b1, a2, b2, chunk_size=10000):
    results = []
    for i in range(0, len(a1), chunk_size):
        chunk_a1 = a1[i:i+chunk_size]
        chunk_b1 = b1[i:i+chunk_size]

        # Process chunk on GPU
        chunk_result = auto_compute_distance(
            chunk_a1, chunk_b1, a2, b2,
            metric="jensen_shannon",
            use_gpu=True
        )
        results.append(chunk_result)

    return np.concatenate(results)

    calc = DistanceCalculator()

    # Your custom computation logic here

# 2. Add to the Metric type in metrics_factory.py
Metric = Literal[

Performance Optimization Tips

GPU Memory Management

  • Use `xp.asarray()` with explicit dtype specification
  • Minimize CPU-GPU data transfers
  • Use in-place operations when possible
  • Batch operations to maximize GPU utilization

Numerical Stability

  • Add small epsilon values to avoid division by zero
  • Use `xp.clip()` to prevent numerical overflow
  • Handle special cases (NaN, inf) appropriately
  • Use log-sum-exp trick for numerical stability

Testing Strategy

def test_metric_properties():
    """Test mathematical properties of distance metrics."""
    # Test symmetry (if applicable)
    d1 = compute_metric(a1, b1, a2, b2)
    d2 = compute_metric(a2, b2, a1, b1)
    assert xp.allclose(d1, d2), "Metric should be symmetric"

    # Test triangle inequality (if applicable)
    d12 = compute_metric(a1, b1, a2, b2)
    d23 = compute_metric(a2, b2, a3, b3)
    d13 = compute_metric(a1, b1, a3, b3)
    assert xp.all(d12 + d23 >= d13), "Triangle inequality violated"

    # Test non-negativity
    assert xp.all(d1 >= 0), "Distance should be non-negative"
