Overview

MethylDetector is a comprehensive bioinformatics tool designed for the detection of differentially methylated positions (DMPs) and differentially methylated regions (DMRs) in genomic datasets. The tool implements advanced statistical methods for comparing methylation patterns between two experimental conditions using centroid-based approaches.

Core Purpose: MethylDetector identifies genomic positions where DNA methylation levels significantly differ between two biological conditions (e.g., treatment vs. control, diseased vs. healthy tissue).

Key Capabilities

  • Statistical Rigor: Multiple testing correction and global significance assessment
  • Scalability: Handles datasets from thousands to millions of genomic positions
  • Performance: GPU-accelerated computation for large-scale analyses
  • Flexibility: Supports single and multiple comparison workflows
  • Data Export: Multiple output formats for downstream analysis

Statistical Framework

Beta Distribution Modeling

DNA methylation data follows a Beta distribution due to its bounded nature (methylation levels range from 0 to 1). MethylDetector models methylation levels at each genomic position using Beta distributions:

X ∼ Beta(α, β)
E[X] = α/(α + β)
Var(X) = αβ/((α + β)²(α + β + 1))

Likelihood Ratio Test (LRT)

For comparing two Beta distributions, MethylDetector uses the Likelihood Ratio Test:

Λ = 2[log L(α₁,β₁,α₂,β₂) - log L(α₀,β₀)]
Λ ∼ χ²(df = 2) under H₀

Where L(α₁,β₁,α₂,β₂) is the likelihood under the alternative hypothesis (different distributions) and L(α₀,β₀) is the likelihood under the null hypothesis (same distribution).

Normal Approximation

For well-behaved Beta distributions with sufficient sample sizes, MethylDetector uses the normal approximation for faster computation:

Z = (μ₁ - μ₂) / √(σ₁²/n₁ + σ₂²/n₂)
Z ∼ N(0,1) under H₀

Automatic Method Selection

MethylDetector intelligently selects the most appropriate statistical method based on data characteristics:

Method Conditions Advantages Computational Cost
Normal Approximation n ≥ 30, well-behaved Beta parameters Fast computation, good power Low
Likelihood Ratio Test Small samples or complex distributions Higher accuracy, robust to violations Medium-High
Method-of-Moments Fallback When MLE fails to converge Guaranteed convergence, fast Low

Decision Criteria

  • Sample Size: n ≥ 30 favors normal approximation
  • Beta Parameters: α,β ≥ 2.0 for normal approximation
  • Mean Values: Extreme means (close to 0 or 1) trigger LRT
  • Convergence: Failed MLE automatically falls back to MoM

False Discovery Rate Correction

Storey's π₀ Estimation

MethylDetector implements Storey's method for estimating the proportion of true null hypotheses:

π₀(λ) = min{1, [1 - (1 - λ) * (m₁/m₀)] / λ}
π₀ = median{π₀(λ) for λ ∈ [0.01, 0.95]}

Where m₁ is the number of p-values > λ and m₀ is the total number of tests.

Q-Value Calculation

Q-values are calculated using the estimated π₀:

q(i) = min{π₀ * m * p(i) / i, q(i+1)}
for i = m, m-1, ..., 1

Global Significance (Stouffer's Method)

For assessing overall experimental significance:

Z_combined = Σ wᵢZᵢ / √Σ wᵢ²
p_global = 2 * (1 - Φ(|Z_combined|))

Where Zᵢ are individual z-scores and wᵢ are optional weights.

GPU Acceleration

NVIDIA RAPIDS Integration

MethylDetector leverages the NVIDIA RAPIDS ecosystem (CuPy, cuDF, cuML) for GPU-accelerated computations, providing significant performance improvements for large datasets.

GPU-Optimized Operations

  • Vectorized Computations: Batch processing of millions of positions
  • Memory Management: Efficient GPU memory allocation and transfer
  • Parallel Processing: Concurrent batch processing with ThreadPoolExecutor
  • Automatic Fallback: Seamless CPU fallback when GPU is unavailable

Data Formats and Export

Input Format: Extended Centroids

MethylDetector processes HDF5 files containing extended centroid data with statistical summaries:

# Required HDF5 datasets: /methylation_data/ ├── pos: int32 array # Genomic positions ├── mC: float64 array # Methylated cytosine counts ├── uC: float64 array # Unmethylated cytosine counts ├── N: int32 array # Total coverage ├── Sx: float64 array # Sum of methylation levels ├── Sx2: float64 array # Sum of squared methylation levels ├── log_x_sum: float64 array # Sum of log(methylation levels) └── log_1_minus_x_sum: float64 array # Sum of log(1-methylation levels)

Quality Control

  • Sample Size Validation: Minimum N ≥ 10 for reliable p-values
  • Data Integrity: Checks for NaN, Inf, and invalid values
  • Range Validation: Methylation levels ∈ [0,1], counts ≥ 0
  • Position Filtering: Removes positions with insufficient data

Error Handling

Robust Error Recovery

  • MLE Convergence: Automatic fallback to Method-of-Moments
  • GPU Failure: Seamless CPU fallback
  • Memory Issues: Batch processing with configurable sizes
  • File I/O: Graceful handling of permission and disk space issues
