\section{Introduction}

In MethylDetector (built on MethylUtils), the \textbf{effect size} is the canonical biological score used for ranking Differentially Methylated Positions (DMPs). It combines:

\begin{itemize}
    \item \textbf{Mean separation} through $|\Delta \mu|$.
    \item \textbf{Continuous ECDF overlap} from PCHIP-derived PDFs.
    \item \textbf{Separate variance penalties} through a reliability term controlled by $\lambda_{\mathrm{var}}$.
\end{itemize}

The formula is:

\begin{equation}
    \mathrm{effect\_size}
    =
    |\Delta \mu|
    \cdot
    (1 - O_{\mathrm{ECDF}})
    \cdot
    \exp\left(-\lambda_{\mathrm{var}} (\sqrt{\sigma_1^2} + \sqrt{\sigma_2^2})\right)
\end{equation}

This preserves a direct biological interpretation: large mean shifts, low distributional overlap, and tight within-group distributions lead to a higher score.

The detector/explorer pipeline uses a staged execution strategy for efficiency:

\begin{itemize}
    \item \textbf{Statistical test}: Welch-style mean-difference testing plus FDR correction.
    \item \textbf{$\Delta \mu$ reduction}: apply a mean-difference gate before any CPU-bound overlap calculation.
    \item \textbf{Continuous ECDF stage}: compute $O_{\mathrm{ECDF}}$ and the final effect size only on the reduced set.
\end{itemize}

\section{Welch's $d$ (Standardized Mean Difference)}

Welch's $d$ measures effect magnitude, robust to unequal variances $n_1 \neq n_2$:

\begin{equation}
    d = \frac{|\mu_1 - \mu_2|}{\sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}}
    \label{eq:welch_d}
\end{equation}

where:
\begin{itemize}
    \item $\mu_1, \mu_2$: Methylation means ($\mu = Sx / N$ from centroid).
    \item $\sigma_1^2, \sigma_2^2$: Sample variances ($\sigma^2 = (Sx2 - Sx^2/N)/(N-1)$).
    \item $n_1 = N_1, n_2 = N_2$: Coverage (reads/position).
\end{itemize}

$d$ is \emph{capped} at $50$ to prevent overflow in downstream sigmoid.

\section{Distribution Overlap Metrics}

Overlap $O \in [0, 1]$ ($O=1$: identical, $O=0$: no overlap) corrects $d$ for distribution similarity.

\subsection{Approximate Overlap ($O_\text{approx}$)}

\begin{enumerate}
    \item \textbf{Discrete Bhattacharyya} (preferred, from `binned\_stats`):
    \begin{equation}
        O_\text{Bh} = \sum_b \sqrt{p_{1b} \cdot p_{2b}}, \quad p_{ib} = \frac{\text{bin\_counts}_{ib}}{\sum_b \text{bin\_counts}_{ib}}
        \label{eq:bhattacharyya}
    \end{equation}
    Vectorized over positions; fast ($O(n_\text{pos} \cdot n_\text{bins})$).

    \item \textbf{Normal fallback} (if no bins):
    \begin{equation}
        O_\text{Norm} = 2 \Phi\left(-\frac{d}{2}\right)
        \label{eq:normal_overlap}
    \end{equation}
    where $\Phi$ is standard normal CDF.
\end{enumerate}

Implemented in \texttt{welch\_d\_fast\_overlap\_approx()}.

\subsection{Refined Overlap ($O_\text{KS}$): ECDF Kolmogorov--Smirnov}

KS statistic $D = \sup_x |F_1(x) - F_2(x)|$ from empirical CDFs ($F_i$ via PCHIP on $\text{bin\_edges}, \text{bin\_counts}$):

\begin{equation}
    O_\text{KS} = 1 - D
    \label{eq:ks_overlap}
\end{equation}

Implemented in \texttt{welch\_d\_ks\_overlap()} with \texttt{ECDFView.\_cdf\_batch()}.

\section{Bounded Effect Size Formula}

Core formula (both approx/refined). The reported effect is shifted so that no difference gives 0 and strong separation gives 1:
\begin{equation}
    \text{effect} = \max\left(0,\; 2\,\sigma\left( s \cdot d \cdot (1 - O) \right) - 1\right)
    \label{eq:bounded_effect}
\end{equation}

where:
\begin{itemize}
    \item $\sigma(z) = \frac{1}{1 + e^{-z}}$ (logistic sigmoid).
    \item $s = 3.0$ (scale hyperparameter; default in detector config and Explorer).
    \item $O$: Overlap ($O_\text{approx}$ or $O_\text{KS}$). Range of effect is $[0,1]$; no difference $\Rightarrow$ effect $= 0$.
\end{itemize}

\textbf{Interpretation}:
\begin{itemize}
    \item $d \to 0$ or $O \to 1$: effect $\to 0$ (no difference / full overlap).
    \item $d \gg 0$, $O \to 0$: effect $\to 1$ (perfect discrimination).
\end{itemize}

\subsection{Refined formula: alignment with KS test}

The refined (ECDF) effect size uses the \emph{same} statistic as the two-sample KS test so that effect size correlates well with the test $p$-value. The test statistic is $T = \sqrt{n_{\text{eff}}} \cdot D$, with $n_{\text{eff}} = 2/(1/n_1 + 1/n_2)$. Then
\begin{equation}
    \text{effect}_{\text{refined}} = \max\left(0,\; 2\,\sigma\left( s \cdot d \cdot \min(T, T_{\max}) \right) - 1\right), \quad T_{\max} = 15.
\end{equation}
So $d$ retains biological meaning (standardized mean difference) and $T$ (separation scaled by effective sample size) aligns with significance; no difference gives effect 0, strong separation gives effect 1.

\section{MethylDetectorExplorer: Two-Phase Optimization}

\begin{enumerate}
    \item \textbf{Phase 1}: Compute $O_\text{approx}$ on subsample ($\sim 1\%$), sort by effect$_\text{approx}$.
    \item \textbf{Phase 2}: Heuristic chooses $K$ (decay, knee, threshold, fraction, fixed); compute effect$_\text{refined}$ only for top $K$.
\end{enumerate}

See \texttt{methyl\_detector.explorer.MethylDetectorExplorer}.

\section{Precision of the ``Exact'' Effect Size}

The refined (ECDF-based) effect size is \emph{exact} only relative to the following approximations:

\begin{itemize}
    \item \textbf{Binned ECDF}: The CDF is built from histogram \texttt{bin\_counts} at \texttt{bin\_edges}, not from raw sample values. Finer bins (e.g.\ 20--50) give a better approximation to the true distribution; coarse bins can smooth out separation and under- or overestimate $D$.
    \item \textbf{PCHIP interpolation}: The ECDF is interpolated between bin edges via PCHIP. This gives a smooth, monotone CDF but is still an approximation to the true empirical CDF.
    \item \textbf{Finite KS grid}: The KS statistic is computed as $\max_{x \in \text{grid}} |F_1(x) - F_2(x)|$ on a fixed grid (default 256 points in $[0,1]$). The true $D = \sup_x |F_1 - F_2|$ may occur between grid points, so we can slightly underestimate $D$ (and thus the effect size) when the maximum is sharp.
\end{itemize}

Approximate (Normal) and refined (KS) effect sizes can still differ in \emph{scale} because they use different overlap notions: Normal uses $O = 2\Phi(-d/2)$ (overlap of two Normals with the same $d$), while refined uses $O_{\text{KS}} = 1 - D$ (from the actual ECDFs). For comparable ordering, use the same overlap mode (e.g.\ \texttt{--approx-overlap normal}) and the same scale; the refined value is then the more distribution-aware estimate for the top positions.
