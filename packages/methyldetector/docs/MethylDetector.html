Overview

MethylDetector is a sophisticated genomics tool designed for detecting differentially methylated positions (DMPs) between two groups of samples using enhanced centroid-based statistical comparison.

Key Features

  • Statistical Rigor: Beta distribution modeling with LRT and normal approximation methods
  • GPU Acceleration: NVIDIA RAPIDS integration for large-scale analyses
  • FDR Correction: Storey's π₀ estimation and q-value calculation
  • Flexible Filtering: Multi-criteria DMP selection with biological relevance
  • Multiple Export Formats: CSV, JSON, HDF5, and Parquet support

Architecture

MethylDetector follows a modular architecture with clear separation of concerns:

methyl_detector/ ├── __init__.py # Package initialization and exports ├── __main__.py # Module execution entry point ├── core/ │ ├── __init__.py │ ├── methyldetector.py # Main MethylDetector class │ ├── centroid_comparer.py # Enhanced centroid-based comparison with GPU acceleration │ ├── dmp_filter.py # DMP filtering and analysis │ ├── dmp_selector.py # DMP selection algorithms ├── models/ │ ├── __init__.py │ ├── config.py # Pydantic configuration models │ └── results.py # Pydantic result models ├── cli/ │ ├── __init__.py │ └── main.py # Command line interface ├── utils/ │ ├── __init__.py │ ├── core.py # Core GPU and configuration utilities │ ├── file_utils.py # File and path utilities │ └── sample_handler.py # Sample and centroid handling └── MethylDetector.pdf # Original documentation

Core Components

  • MethylDetector: Main pipeline orchestrator
  • SmartCentroidComparator: Advanced statistical comparison engine
  • DMPFilter & DMPSelector: Biological relevance filtering
  • CentroidHandler: HDF5 data management via MethylSample
  • GPUConfig: RAPIDS GPU acceleration management

Installation & Setup

Container Deployment: MethylDetector is designed to run in a CUDA-enabled container environment with pre-configured dependencies.

Prerequisites

  • Python 3.10+
  • NVIDIA GPU with CUDA support (optional, falls back to CPU)
  • MethylUtils library (must be in PYTHONPATH)
  • RAPIDS ecosystem (cuDF, cuML, CuPy) for GPU acceleration

Dependencies

# Core dependencies numpy >= 1.26.0 pandas >= 2.2.0 scikit-learn >= 1.4.0 h5py >= 3.10.0 pydantic >= 2.6.0 # Statistical and scientific computing scipy matplotlib >= 3.8.0 plotly >= 5.18.0 seaborn >= 0.13.2 # CLI and utilities click >= 8.1.0 tqdm >= 4.66.0

Container Setup

The application executes inside a container defined in ~/Work/cuda. Ensure the container has:

  • MethylUtils in the Python path (/home/ubuntu/MethylUtils)
  • RAPIDS libraries installed
  • Proper GPU driver mapping

Usage Guide

Command Line Interface

# Basic usage methyl-detector --config config.json # With verbose logging methyl-detector --config config.json --verbose

Python API

from methyl_detector import MethylDetector, MethylDetectorConfig # Load configuration config = MethylDetectorConfig.from_json("config.json") # Run analysis detector = MethylDetector(config) results = detector.run() # Access results print(f"Found {len(results.biologically_significant_dmps)} DMPs") for dmp in results.biologically_significant_dmps: print(f"Position {dmp.position}: p={dmp.p_value:.2e}, q={dmp.q_value:.2e}")

Configuration Example

{ "mode": "single", "centroid1_path": "data/group1_centroid.h5", "centroid2_path": "data/group2_centroid.h5", "output_dir": "results/", "alpha": 0.05, "apply_dmp_filtering": true, "dmp_selection_method": "combined", "min_samples_per_group": 10, "enable_gpu": true, "batch_size": 10000 }

  • config: MethylDetectorConfig instance

Execute the complete DMP detection pipeline.

Returns: MethylDetectorResult with statistical and biological DMPs

Configuration Classes

MethylDetectorConfig

Pydantic model for configuration validation and management.

Key Fields:
  • mode: "single" or "multiple" analysis mode
  • centroid1_path, centroid2_path: Input HDF5 files
  • alpha: Significance threshold (default: 0.05)
  • enable_gpu: GPU acceleration toggle
  • apply_dmp_filtering: Enable biological filtering

Result Classes

MethylDetectorResult

Container for analysis results.

Attributes:
  • statistically_significant_dmps: List of statistical DMPs
  • biologically_significant_dmps: List of filtered biological DMPs
  • comparison_stats: Overall comparison statistics
  • metadata: Analysis metadata

Configuration

Parameter Type Default Description
mode str Required "single" or "multiple" analysis mode
alpha float 0.05 Statistical significance threshold
min_samples_per_group int 10 Minimum samples required per group
enable_gpu bool true Enable GPU acceleration if available
batch_size int 10000 Processing batch size for memory management
apply_dmp_filtering bool true Apply biological relevance filtering
dmp_selection_method str "combined" Selection method: "overlap", "jeffreys", or "combined"

Data Formats

Input: Extended Centroids

MethylDetector processes HDF5 files containing centroid data with statistical summaries:

Required fields: - pos: genomic positions (uint32) - mC: methylated counts (uint32) - uC: unmethylated counts (uint32) - N: sample count (uint32) - Sx: sum of methylation levels (float32) - Sx2: sum of squared methylation levels (float32) - log_x_sum: sum of log(methylation) (float32) - log_1_minus_x_sum: sum of log(1-methylation) (float32)

Output Formats

  • CSV: Human-readable results with all DMP information
  • JSON: Structured results with metadata
  • HDF5: Binary format with compression for large datasets
  • Parquet: Columnar format optimized for analytics

GPU Acceleration

NVIDIA RAPIDS Integration

MethylDetector leverages RAPIDS for GPU-accelerated statistical computing, providing significant performance improvements for large-scale analyses.

GPU-Optimized Operations

  • Beta distribution parameter estimation
  • Likelihood ratio test computation
  • Statistical divergence calculations
  • Matrix operations and data transformations

Automatic Fallback

The system automatically falls back to CPU computation when:

  • GPU is not available or not CUDA-capable
  • RAPIDS libraries are not installed
  • GPU memory is insufficient
  • GPU computation fails

Troubleshooting

Common Issues

MethylUtils Import Error

Ensure MethylUtils is in the Python path. In the container environment, it should be at /home/ubuntu/MethylUtils.

GPU Not Detected

Check CUDA installation and GPU drivers. The system will fall back to CPU if GPU is unavailable.

Memory Issues

Reduce batch size in configuration for large datasets. Enable GPU acceleration to reduce memory pressure on CPU.

Logging

Enable verbose logging with --verbose flag or set logging level in configuration:

import logging logging.basicConfig(level=logging.DEBUG)

Performance Optimization

  • Use GPU acceleration for datasets > 100K positions
  • Adjust batch size based on available memory
  • Pre-filter positions with insufficient coverage
  • Use HDF5 or Parquet formats for large result sets
