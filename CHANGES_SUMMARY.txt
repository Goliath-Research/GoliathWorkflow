USAGE EXAMPLES:
--------------

1. Automatic Validation (using centroid metadata):

     "validation_mode": "real",
     "centroid1_validation_samples": "use_metadata",
     "centroid2_validation_samples": "use_metadata"
   }

2. Manual Sample Paths:
   {
     "validation_mode": "real",
     "centroid1_validation_samples": ["/path/sample1", "/path/sample2"],
     "centroid2_validation_samples": ["/path/sample3", "/path/sample4"]
   }

3. Synthetic (default - backward compatible):
   {
     "validation_mode": "synthetic",
     "n_validation_samples": 100
   }
