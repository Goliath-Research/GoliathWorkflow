9  MethylAlignmentQC

9.1 Role

methylalignmentqc parses alignment and duplication metrics from Picard-style deduplication files and Parabricks WGBS JSON, then writes normalized per-sample JSON with guardrails that gate SamplePrep before methylation extraction.

Operator guide: Usage ch.03 — Sample Prep and QC.

The package is deterministic: parsing, normalization, threshold checks, and cycle-quality screening — not new statistical inference on methylation.

9.2 Input metrics

9.2.1 Picard-style deduplication metrics

Parabricks emits tab-separated *deduplicate_metrics.txt (or *duplication_metrics.txt). The parser (methyl_alignment_qc/core/parser.py) reads columns such as PERCENT_DUPLICATION, read-pair counts, and unmapped reads. These populate summary_stats on the export JSON.

Optional config guardrails (actionConfig.alignment_qc.optional_guardrails.duplication_rate_max, min_pf_reads) can fail samples with excessive PCR duplication even when cycle quality passes.

9.2.2 Parabricks WGBS metrics JSON

Each sample directory should contain {sample_id}.json with sections including:

  • quality_yield — PF reads, Q30 bases
  • mean_quality_by_cycle — per-cycle mean Phred (Read 1 then Read 2)
  • gc_bias_summary, insert_size_metrics
  • pre_adapter_summaries — deamination and OxoG artifact qscores

Guardrails in wgbs_parabricks_qc.py evaluate PF%, Q30, mean/min cycle quality, GC/AT dropout, median insert size, and deamination/OxoG scores before extraction proceeds.

9.2.3 Alignment-layer guardrails

Beyond sequencing/library checks, alignment_derived_qc.py derives mapping rate, secondary/supplementary rate, and GC coverage uniformity from Picard dedup and GC bias tables. When alignment_guardrails.flagstat_enabled is true, bam_flagstat.py runs samtools flagstat on the aligned BAM and gates properly paired rate and supplementary alignments.

Analyte profiles enable these guardrails by default for cfdna and buffy_coat. See the sample preparation flow for thresholds and operator guidance.

9.3 Export JSON (V2)

The worker writes row-oriented JSON validated against schemas/config/alignment_qc/exported_sample_qc_v2.schema.json. Key blocks:

Block Role
guardrails.details Per-metric pass/fail, value, normal range, operator message
guardrails.overall_pass Bound to workflow qcPass
guardrails.screening Cycle-quality disposition and recommended trim bases
qc_history Append-only audit (initial + post-remediation retries)
alignment_stats Derived mapping and GC uniformity metrics
alignment_flagstat samtools flagstat summary (when enabled)

9.4 Cycle screening and remediation

When cycle_screening.enabled is true, cycle_quality_screening.py inspects Read 1 and Read 2 separately. Dispositions include:

Disposition Meaning
USE_CURRENT_ALIGNMENT Pass
REALIGN_TRIM Fixable read-end dip; fastp trim + forced realign
INVESTIGATE_MULTI_REGION Manual review
INVESTIGATE_GUARDRAIL_ONLY Cycles OK; check duplication/depth
NOT_FIXABLE Terminal fail

SamplePrep binds remediateAlignment from screening output; FASTQs must remain on disk until final QC disposition.

9.5 cfDNA fragmentomics (optional)

When primary_analyte is cfdna, insert-size histogram guardrails may run via fragmentomics.py after alignment QC passes and before extraction.

9.6 Summary statistics

When the package computes duplication rate, it applies straightforward algebra:

\[ \operatorname{duplication\ rate} = \frac{\text{duplicate reads}}{\text{total reads}}. \tag{9.1}\]

9.7 Publication guidance

Describe methylalignmentqc as:

  • a QC ingestion and normalization layer,
  • dependent on upstream Picard/Parabricks metrics,
  • deterministic in parsing and guardrail logic, and
  • gating extraction via SamplePrep workflow bindings.
