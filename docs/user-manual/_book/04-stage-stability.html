6  Stage: Stability

6.1 Purpose

Run repeated train/validation iterations to identify DMPs that recur across runs and materialize a stable production panel.

6.2 Entry command

source .venv/bin/activate
methyl-validation --project /work/prostate-cancer/configs/project_Healthy_vs_PCa1-4-CG.json --stability

Optional strict FeatureCuts alignment:

source .venv/bin/activate
methyl-validation --project /work/prostate-cancer/configs/project_Healthy_vs_PCa1-4-CG.json \
  --stability --stability-featurecuts --stability-target-ba 0.95 --stability-min-selected-dmps 1000

6.3 Required config keys

Under step_config.validation:

  • n_iterations, train_fraction, seed
  • run_stability
  • stability_dmp_freq
  • stability_min_balanced_accuracy
  • stability_gene_freq
  • optional adaptive stop controls:
    • stability_early_stop_enabled
    • stability_min_iterations
    • stability_convergence_window
    • stability_convergence_jaccard
    • stability_convergence_max_size_delta
    • stability_convergence_patience
  • optional FeatureCuts controls:
    • stability_featurecuts_enabled
    • stability_target_balanced_accuracy
    • stability_min_selected_dmps

6.4 Composable workflow profiles

DomainProgram workflows support selectable paths via context profiles in workflow_engine/domain/profiles/. Use methyl-validation run-workflow or methyl-workflow-run with --context-file.

Gene stability without DMP FeatureCuts (discovery DMPs → mapper → enricher → stability on enricher genes):

  • Profile: gene_enricher_stability.profile.json
  • Program: mc_gene_enricher_stability.program.json
  • Set stability_featurecuts_enabled: false, stability_gene_featurecuts_enabled: false, stability_gene_freq as needed
  • Mapper uses dmps-*-discovery.csv; enricher applies disease filters from step_config.enricher

DMP panel stability (split detector + pipeline.dmp_select): profile dmp_panel_stability or full_biomarker_gene_fc.

Discovery DMPs → broad mapper → gene FeatureCuts (stable gene panel for model): profile discovery_gene_featurecuts with pca1_5_mc_stability.program.json. Mapper uses dmps-*-discovery.csv; pipeline.dmp_select still runs so pipeline.gene_select has classifier DMP exports for validation. Biomarker/PPI pre-filter is off by default (largest gene pool); enable with "runBiomarkerFilter": true in context.

Biomarker / PPI pre-filter (validation.biomarker_filter): optional via ${runBiomarkerFilter}; modes ppi_only, disease_only, disease_and_ppi under step_config.validation or gene_selection. Can run on mapper gene pools without gene FeatureCuts.

See docs/domain_program_language.md for the full profile matrix and IF branch flags (runDmpSelection, runGeneFeaturecuts, …).

6.5 Process model

6.6 Expected outputs

  • <mc_root>/stability/stable_dmps_production.csv
  • <mc_root>/stability/stability_summary.json
  • <mc_root>/all_metrics.csv
  • <mc_root>/metrics_summary.json
  • <mc_root>/baseline_manifest.json

Where <mc_root> is: <output_base>/<project_name>/monte_carlo_runs/

6.7 Success checks

  • stable_dmps_production.csv exists and is non-empty.
  • all_metrics.csv has successful rows near expected run count.
  • stability_summary.json reports configured thresholds.
  • if adaptive stop is enabled, stability_summary.json includes early_stopping diagnostics (triggered, checkpoint history, and stop iteration when applicable).

6.8 Do not do this

  • Do not proceed to freeze when stable panel is missing or empty.
  • Do not interpret blind outputs as stability quality evidence.

6.9 Recovery

  • Resume interrupted run:
source .venv/bin/activate
methyl-validation --project /work/prostate-cancer/configs/project_Healthy_vs_PCa1-4-CG.json --stability --resume
  • If panel is too small: lower stability_dmp_freq or increase n_iterations.
  • If run quality is too low: tune detector and/or adjust stability_min_balanced_accuracy.
